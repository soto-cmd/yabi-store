# YABI Store

Frontend de tienda online desarrollado con HTML, CSS y JavaScript puro.

## Incluye

- Diseño responsive para móvil y escritorio
- Paleta rosa elegante y profesional
- Portada comercial
- Categorías
- Catálogo de productos
- Buscador
- Filtros por categoría
- Carrito lateral
- Persistencia del carrito con localStorage
- Preparación de pedido para WhatsApp

## Estructura

- `index.html` — estructura principal
- `css/style.css` — diseño y responsive
- `js/app.js` — productos, filtros, búsqueda y carrito

## Personalización

Los productos de demostración se encuentran en `js/app.js` dentro del arreglo `products`.

Antes de usar pedidos reales, reemplazar `595XXXXXXXXX` por el número de WhatsApp de YABI Store.

Este proyecto funciona completamente del lado del cliente y no utiliza base de datos ni backend.
